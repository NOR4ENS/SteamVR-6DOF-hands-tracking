# SteamVR 6DoF Hand Tracking & Gestures (VMT Knuckles)

Отслеживание обеих рук через обычную веб-камеру или смартфон (**6DoF** позиция и поворот + **5 независимых пальцев**) с эмуляцией контроллеров **Valve Index (Knuckles)** в **SteamVR** через драйвер **Virtual Motion Tracker (VMT)**.

Весь проект оформлен в **один автономный файл** [`vr_hand_tracking.py`](vr_hand_tracking.py): в него уже встроены PEP 723 метаданные для `uv` и автосоздание локального `.venv` с установкой всех библиотек при первом запуске — отдельный `requirements.txt` не нужен.

---

## Возможности

- **6DoF-трекинг обеих рук** (левая и правая одновременно) по одной камере через MediaPipe Hands + передача по OSC на VMT (`127.0.0.1:39570`).
- **Независимое отслеживание всех 5 пальцев** (скелет Valve Index / Knuckles в OpenVR + аналоговые оси пальцев).
- **Два режима работы (`[G]`)**:
  - **`WAND`** — вертикальный контроллер для удобной навигации в SteamVR, VR-плеерах и меню + чёткие щипки для `Trigger`, `Grip`, `A`, `B`, `System`.
  - **`HANDS`** — 3D-руки 1-в-1 для игр с физикой рук (например, *Hand Physics Lab*), где каждый палец шевелится отдельно, а хват и щипки работают даже при повороте руки боком.
- **Профиль под ультраширокую камеру телефона `0.5x` (`[W]`)** и обычный профиль `1x`.
- **1€-стабилизация (`[S]`)**: 3 уровня сглаживания позиции, глубины и поворота (`LOW` / `MED` / `HIGH`) с мёртвыми зонами, подавлением 1-кадровых выбросов и защитой от перескока `Left`/`Right`.
- **Подстройка под реальное расположение камеры**: компенсация наклона камеры на столе вверх (`[` / `]`), разворот ладоней на `180°` (`[F]`), зеркалирование кадра (`[M]`), режим камеры на столе или на шлеме (`[C]`), переключение камер на лету (`[N]` / `[0]`–`[5]`).

## Системные требования

- **ОС:** Windows 10 / Windows 11 (64-bit)
- **Steam и SteamVR** (установленный и настроенный)
- **Драйвер Virtual Motion Tracker (VMT v0.15):**
  https://github.com/gpsnmeajp/VirtualMotionTracker/releases
- **Python 3.9–3.12** *(рекомендуется **Python 3.11.9 (64-bit)**)*:
  https://www.python.org/downloads/release/python-3119/  
  > **Важно:** `mediapipe==0.10.21` **не работает** на Python 3.13+, поэтому используйте Python **3.11** (или `uv`).
- **Камера:** USB веб-камера или смартфон в качестве камеры ПК (*Iriun Webcam*, *DroidCam* или *scrcpy + OBS Virtual Camera*). Если нужна 0.5 камера то лучше scrpy.

### Используемые Python-библиотеки (ставятся автоматически)

- `mediapipe==0.10.21`
- `opencv-python==4.11.0.86`
- `numpy==1.26.4`
- `scipy>=1.11,<1.18`
- `python-osc==1.10.3`
- `pynput==1.8.2`
- `protobuf==4.25.9`

## Установка и запуск с нуля

### Шаг 1. Установка SteamVR и драйвера VMT v0.15
1. Установите **SteamVR** в Steam.
2. Скачайте релиз **VMT v0.15** со страницы [VirtualMotionTracker Releases](https://github.com/gpsnmeajp/VirtualMotionTracker/releases) и распакуйте архив в удобную папку.
3. Запустите `vmt_manager.exe` (внутри `vmt_manager/`) и нажмите кнопку установки драйвера в SteamVR (**Install**).
4. Перезапустите SteamVR и в настройках SteamVR (**Настройки → Дополнения запуска** / *Startup/Shutdown*) убедитесь, что дополнение `vmt` включено, а **Safe Mode** выключен.

> Для шлема смартфона можно использовать любой совместимый VR-стример в SteamVR (например, *ALVR*, *iVRy* и т.п.). При отсутствии HMD переключите координатную привязку в режим `ROOM` клавишей `[H]` или флагом `--space room`.

### Шаг 2. Установка Python 3.11
1. Скачайте **Windows installer (64-bit)** для **Python 3.11.9**:
   https://www.python.org/downloads/release/python-3119/
2. При установке **обязательно поставьте галочку `Add python.exe to PATH`**.

### Шаг 3. Скачивание скрипта
- Нажмите на файл `vr_hand_tracking.py` в репозитории и нажмите кнопку **Download raw file** (или скачайте весь репозиторий: зелёная кнопка **Code → Download ZIP**).
- Сохраните `vr_hand_tracking.py` в отдельную папку (например, `Desktop\VR` или `C:\VR`).

### Шаг 4. Первый запуск

1. Запустите **SteamVR** и включите камеру/приложение веб-камеры.
2. Откройте терминал (`cmd` или PowerShell) в папке со скриптом и выберите один из способов:

#### Вариант А — Автоматический запуск через обычный Python (рекомендуется)
```powershell
python vr_hand_tracking.py
```
При первом запуске скрипт сам создаст рядом папку `.venv`, установит туда все 7 нужных библиотек и сразу запустит трекинг. Все последующие запуски стартуют мгновенно.

Если нужно сначала только установить библиотеки без запуска камеры:
```powershell
python vr_hand_tracking.py --install-deps
```

#### Вариант Б — Запуск в 1 команду через `uv` (PEP 723)
Если у вас установлен [`uv`](https://docs.astral.sh/uv/), даже Python 3.11 ставить вручную не нужно — `uv` сам подтянет совместимый Python и зависимости во временное окружение:
```powershell
uv run vr_hand_tracking.py
```

#### Вариант В — Полностью ручная установка (без автоустановщика)
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install "mediapipe==0.10.21" "opencv-python==4.11.0.86" "numpy==1.26.4" "scipy>=1.11,<1.18" "python-osc==1.10.3" "pynput==1.8.2" "protobuf==4.25.9"
.\.venv\Scripts\python.exe vr_hand_tracking.py --no-auto-install
```

*(Посмотреть точный список пакетов в любой момент можно командой `python vr_hand_tracking.py --print-requirements`.)*

## Первая калибровка (10 секунд)

1. В окне камеры убедитесь, что в верхней строке горит **`SteamVR VMT: ONLINE`** (если написано `waiting`, проверьте SteamVR и драйвер VMT).
2. Если открылась не та камера — нажмите **`N`** (перебор) или цифру **`0`–`5`**.
3. Если руки кажутся отзеркаленными — нажмите **`M`**, если ладони в VR развёрнуты к лицу — нажмите **`F`**.
4. Если камера стоит на столе и смотрит снизу вверх — выровняйте угол клавишами **`[` / `]`**.
5. Вытяните руки перед собой в удобное нейтральное положение и нажмите **`SPACE`** (Пробел) — это задаст центр вашей игровой зоны.
6. Для VR-игр переключите режим на **`HANDS`** клавишей **`G`** (или запускайте сразу с `--mode hands`).

## Горячие клавиши в окне трекинга

| Клавиша | Действие |
|---|---|
| `SPACE` | Калибровка центра рук (по текущему положению видимых рук) |
| `G` | Переключить режим контроллера: **`WAND`** (меню/плееры) ↔ **`HANDS`** (3D-руки и 5 пальцев) |
| `S` | Уровень стабилизации: **`LOW`** → **`MED`** → **`HIGH`** |
| `W` | Профиль объектива: **`0.5x` (`wide`)** ↔ **`1x` (`normal`)** |
| `F` | Развернуть ладони на `180°` (если в VR ладони смотрят не в ту сторону) |
| `M` | Зеркалирование кадра по горизонтали (`ON` / `OFF`) |
| `[` / `]` | Компенсация наклона камеры на столе вверх/вниз (`-5°` / `+5°`) |
| `H` | Система координат: **`AUTO`** → **`HMD`** (привязка к шлему) → **`ROOM`** (привязка к комнате) |
| `N` | Переключиться на следующую доступную веб-камеру (`0..5`) |
| `0` – `5` | Выбрать веб-камеру напрямую по индексу |
| `C` | Положение камеры: **`Desk-Cam`** (на столе) ↔ **`HMD-Cam`** (на шлеме) |
| `K` | Вкл/Выкл дублирования жестов на клавиатуру/мышь (`Grip` → `F`, `Trigger` → `ЛКМ`) |
| `ESC` | Выход (сбрасывает кнопки и отключает виртуальные контроллеры) |

## Жесты

### Режим `HANDS` (3D-руки для игр)
- Все **5 пальцев** двигаются независимо в скелете OpenVR под любым углом поворота кисти (включая боковой).
- **`Trigger`**: сгиб указательного пальца или щипок **Большой + Указательный**.
- **`Grip`**: естественное сжатие среднего, безымянного и мизинца.
- Кнопки `A` и `B` в этом режиме отключены, чтобы не мешать свободным движениям пальцев.
- **`System`** (меню SteamVR): удержание щипка **Большой + Мизинец** (`0.75` с) при прямых указательном и среднем пальцах.

### Режим `WAND` (стоячий контроллер для меню и плееров)
- **`Trigger`**: щипок **Большой + Указательный**.
- **`Grip`**: сжатие кулака (средний + безымянный + мизинец).
- **`B` (Назад)**: щипок **Большой + Средний** при открытой ладони.
- **`A`**: щипок **Большой + Безымянный** при открытой ладони.
- **`System`**: удержание щипка **Большой + Мизинец** (`0.55` с) при открытой ладони.

## Аргументы командной строки

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--camera N` | `0` | Индекс камеры для старта (`0..5`) |
| `--mode {wand,hands}` | `wand` | Стартовый режим управления |
| `--lens {wide,normal}` | `wide` | Профиль объектива (`wide` для `0.5x`, `normal` для `1x`) |
| `--smooth {low,med,high}` | `med` | Уровень 1€-стабилизации |
| `--space {auto,hmd,room}` | `auto` | Пространство координат (`HMD` или `Room`) |
| `--camera-tilt DEG` | `0.0` | Компенсация наклона настольной камеры вверх (в градусах) |
| `--flip-palm` | `False` | Сразу включить разворот ладоней на `180°` |
| `--ip ADDR` | `127.0.0.1` | IP-адрес драйвера VMT |
| `--port PORT` | `39570` | OSC-порт драйвера VMT |
| `--desktop-binds` | `False` | Дублировать `Grip`/`Trigger` на клавишу `F` и `ЛКМ` |
| `--install-deps` | `False` | Только создать `.venv`, установить зависимости и выйти |
| `--print-requirements` | `False` | Вывести список зависимостей для `pip` и выйти |
| `--no-auto-install` | `False` | Не устанавливать зависимости автоматически |
| `--dry-run-frames N` | `0` | Тестовый прогон `N` кадров без окна (для проверки камеры) |

Пример запуска с параметрами для VR-игры с камерой `#1` и высокой стабилизацией:
```powershell
python vr_hand_tracking.py --camera 1 --mode hands --lens wide --smooth high --camera-tilt 30
```

## Частые проблемы

- **`Python 3.13+` при запуске / ошибка установки `mediapipe`**: установите [Python 3.11.9](https://www.python.org/downloads/release/python-3119/) или запускайте через `uv run vr_hand_tracking.py`.
- **`SteamVR VMT: waiting` не меняется на `ONLINE`**: проверьте, что в SteamVR запущен драйвер `vmt` (через `vmt_manager.exe` или `steamvr.vrsettings`), не включён безопасный режим SteamVR, а порт `39570` не заблокирован.
- **Открылась не та веб-камера** (например, виртуальная камера вместо основной): нажмите **`N`** или цифру **`0`–`5`** в окне трекинга либо передайте `--camera 1` при запуске.
- **Руки смотрят ладонями к лицу**: нажмите **`F`** (разворот ладоней) и при необходимости **`M`** (зеркалирование), а если камера лежит на столе и смотрит снизу вверх — подкрутите угол клавишей **`]`**.
- **Дрожат руки на ультраширике `0.5x`**: переключите стабилизацию клавишей **`S`** в **`HIGH`** и проверьте, что выбран профиль объектива **`0.5x`** (клавиша **`W`**).
- **Быстрая проверка камеры без VR**:
  ```powershell
  python vr_hand_tracking.py --camera 0 --dry-run-frames 10
  ```
